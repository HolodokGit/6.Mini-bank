# Мини-банк

Учебный проект JavaScript. Консольный бэкэнд, имитирующий работу банка.

## Возможности

- Создание поользователей
- Создание счетов
- Пополнение счета
- Снятие средств
- Перевод между счетами
- История операций
- Обработка ошибок
- Асинхронные операции (имитация задержек)
- Логирование операций
- Экспорт данных в JSON
- Просмотр баланса через геттер

## Технологии

- JavaScript (ES Modules)
- Mocha + Chai (тесты)

## Запуск

1. Установить и запустить локальный сервер
2. Открыть `index.html` через localhost
3. Для тестов открыть `pages/tests.html`
